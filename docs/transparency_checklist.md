# Transparency checklist

## Required before manuscript submission

- [ ] radigest commit recorded
- [ ] comparator tool versions recorded
- [ ] reference genome accessions recorded
- [ ] reference FASTA SHA256 checksums recorded
- [ ] synthetic validation cases committed
- [ ] exact commands committed
- [ ] runtime and memory benchmark machine metadata recorded
- [ ] output metrics summarized as TSV
- [ ] mismatches classified by coordinate convention, enzyme cut offset, terminal fragments, same-enzyme adjacency, ambiguous-base handling, or output-object difference
- [ ] no large genomes, FASTQ, BAM, or CRAM files committed directly to Git
- [ ] generated figures and manuscript tables trace back to scripts
- [ ] README states that radigest is not a read simulator, SNP caller, adapter simulator, PCR simulator, or population-genetic simulator
