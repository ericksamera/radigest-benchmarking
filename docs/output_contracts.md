# Output contracts

This repository separates raw tool output, normalized intermediate files,
analysis summaries, benchmark logs, and curated manuscript artifacts.

## Directory meanings

### `results/raw/`

Raw or minimally transformed tool outputs.

Examples:

- direct radigest JSON, GFF3, fragment TSV, and fragment FASTA outputs;
- raw comparator outputs;
- per-run screening outputs;
- manual smoke-test outputs.

These files are reproducible and should normally remain ignored by Git.

### `results/processed/`

Normalized or derived intermediate files.

Examples:

- normalized interval tables;
- validation summaries;
- reference metadata;
- empirical TLEN extraction products;
- input compatibility checks.

These files are reproducible and should normally remain ignored by Git.

### `results/tables/`

Analysis-level tables generated from `results/raw/`, `results/processed/`,
or `benchmark/`.

Examples:

- benchmark run summaries;
- matched-tool timing summaries;
- empirical recovery summaries;
- screening summaries.

These files are reproducible analysis products. They are not the curated
manuscript layer and should normally remain ignored by Git.

### `results/figures/`

Reproducible figures generated from processed files or summary tables.

These are generated outputs. They should normally remain ignored by Git unless
there is a specific reason to archive them separately.

### `benchmark/time/`

Timing files generated by benchmarking tools other than `/usr/bin/time -v`.

### `benchmark/memory/`

`/usr/bin/time -v` output files, including wall time, CPU time, exit status, and
maximum resident set size.

### `benchmark/logs/`

stdout/stderr logs from benchmarked commands and workflow jobs.

### `manuscript_tables/`

Curated final tables intended for the manuscript or supplement.

These are the only table outputs that may be intentionally tracked. Because the
directory is ignored by default, final tables should be staged explicitly:

```bash
git add -f manuscript_tables/*.tsv
```

### `manuscript_figures/`

Curated final figure exports intended for the manuscript or supplement.

These are ignored by default and should be staged explicitly only when they are
final manuscript artifacts.

## Important rule

`make manuscript-tables` is a collector. It reads existing `results/` files and
writes curated `manuscript_tables/` files. It does not rerun every upstream
analysis.

For final release, run all intended analyses first, then run:

```bash
make manuscript-tables
make audit
```

Only stage manuscript tables after confirming that required claim rows are
`present`, not `MISSING`.
